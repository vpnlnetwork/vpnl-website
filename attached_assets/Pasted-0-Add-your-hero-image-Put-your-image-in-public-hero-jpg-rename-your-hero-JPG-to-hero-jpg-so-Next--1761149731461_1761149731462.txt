1) Replace the word “ETHEREUM.ORG” in the mobile burger menu

Search for the drawer/header text:

rg -n "ETHEREUM\.ORG|Ethereum\.org" src app | head
# common hit:

# or src/components/Nav/MobileMenu/MobileMenu.tsx


Open that file and change the brand label:

// OLD (example)

Also change the aria-label on the burger button if it mentions Ethereum:

// NEW
<button aria-label="Open VPNL menu" ...>

9) Make primary color = #1F6FFF everywhere

Search the token or Tailwind variable:

rg -n "--color-primary|--primary|theme.*colors.*primary|brand" src styles tailwind* | head


If CSS variable, set --color-primary: #1F6FFF; in the light theme scope.

If Tailwind config defines colors.primary, set it to #1F6FFF.

This ensures buttons/links use your blue automatically.
