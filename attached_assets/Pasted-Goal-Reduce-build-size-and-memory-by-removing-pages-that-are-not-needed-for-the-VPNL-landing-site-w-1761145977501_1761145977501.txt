Goal
Reduce build size and memory by removing pages that are not needed for the VPNL landing site, while preserving the fork’s structure. Do NOT rebuild the site. Make surgical, idempotent changes. Prefer moving files to __archive/ rather than deleting.

Constraints
- Keep the ethereum.org homepage as our template (app/[locale]/page.tsx) and its layout, shared components, styles and assets actually used by the homepage.
- Keep only English.
- Do not touch node_modules or .next.
- Stop and report if a file is referenced by the homepage before moving it.

Plan (execute in order; stop on error with file+line)

1) Create an archive area:
   - Ensure a top-level folder ./__archive exists (git-keep it).
   - Anything moved there must be outside Next’s /app tree so it’s excluded from routing.

2) Snapshot routes (for log):
   - List immediate children under app/[locale] and app/ that create routes.
   - Output that list before and after pruning.

3) Prune unneeded top-level route directories from app/[locale]/ by moving them to __archive:
   - Candidates to move if present: developers, community, contributing, translations, enterprise, roadmap, nft, defi, wallet, whitepaper, docs, research, history, security, careers, team, bug-bounty, grants, governance, events, blog, learn, layer-2, staking (names may differ—match actual folder names).
   - Before moving each folder, run a fast dependency check:
     - Search for imports from that folder in app/[locale]/page.tsx, layout.tsx, and any components used by the homepage; if found, SKIP moving and report.
   - Use `git mv` to move each safe folder to `__archive/app_locale/<folder>` (preserve structure in case we need to restore).

4) Prune heavy content trees not used by the homepage:
   - If there is a /content, /src/content, /public/content, or similar docs/markdown directory, and it is NOT imported by the homepage files, move it to `__archive/content/...`.
   - Again, run a reference search first; if referenced by homepage, skip and report.

5) Update redirects for removed sections in next.config.js (merge, don’t replace):
   - Ensure we already have: { source: "/demo", destination: "https://demo.vpnl.io", permanent: false }
   - Add redirects to "/" for each removed top-level section (e.g., /developers/:path*, /community/:path*, /contributing/:path*, etc.), only for folders we actually moved. Keep existing config intact.

6) Navigation and locale UI (idempotent checks):
   - Confirm nav renders only: Home · Demo · GitHub · Telegram · Contact.
   - Hide/remove locale switcher if still visible.

7) Build optimization (light touch):
   - In next.config.js ensure:
       eslint: { ignoreDuringBuilds: true },
       typescript: { ignoreBuildErrors: true }
     (Do not change other settings.)
   - Ensure we do NOT include Lighthouse plugin in netlify.toml; only keep @netlify/plugin-nextjs.

8) Commit at the end:
   - Commit message: "chore: prune unused routes/content to reduce build size; add redirects"
   - Do NOT push. Stop and show a concise diff summary: moved folders, next.config.js changes, and any files edited.

Acceptance
- Only homepage + required shared components remain under /app for routing.
- next.config.js has redirects for each removed top-level section.
- English-only UI; no locale switcher.
- Build is lighter and should no longer hang on Netlify.
